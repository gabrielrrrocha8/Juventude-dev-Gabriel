Containers:

container normal

O container normal tem uma largura fixa e centralizada, dependendo do tamanho da tela.


container fluido

O container fluido ocupa toda a largura disponível da tela.


container large

O container large tem uma largura fixa e centralizada, mas com um limite maior que o container normal.


container extra large (xl)

O container extra large tem uma largura fixa e centralizada, mas com um limite ainda maior que o container large.
